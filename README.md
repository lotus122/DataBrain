# DataBrain — AI 数据分析平台

> 用自然语言对话完成数据查询、图表生成与分析报告的轻量级 BI 工具。上传 CSV/Excel 后，业务人员无需写 SQL，直接提问即可获得指标结果、可视化图表和智能分析报告。

## 一、项目介绍

DataBrain 面向"不会写 SQL 但有数据分析需求"的业务用户，提供对话式数据分析体验：

- **自然语言查询**：输入"各区域销售额排名""近 30 天订单趋势"等问题，系统自动识别意图、指标、维度与筛选条件，生成 SQL 并在用户确认后执行。
- **Agent 分析流水线**：意图识别 → 字段匹配 → 条件解析 → SQL 生成 → 人工确认 → 执行 → 图表渲染 → 追问推荐，全流程可视化。
- **自动可视化**：根据问题类型自动选择柱状图、折线图、饼图等，基于 ECharts 渲染。
- **智能报表**：查询结果可保存为报表，支持搜索、时间筛选、查看与导出。
- **数据字典**：自动推断字段类型（数字/日期/文本）、生成中文别名与字段描述。
- **隐私安全**：所有数据仅在浏览器本地解析并存储于 localStorage，不上传业务数据。

## 二、技术架构

```
┌──────────────────────────────────────────────┐
│                  浏览器前端                    │
│                                                │
│  对话查询层   意图识别 / 条件解析 / SQL 生成     │
│     │          （规则引擎，可扩展 LLM 接口）     │
│  分析执行层   本地聚合计算 / 指标汇总 / 洞察     │
│  可视化层     ECharts 图表 / 报告导出           │
│  数据层       SheetJS 解析 CSV/Excel            │
│               localStorage 本地持久化           │
│  可观测层     日志与埋点（config.js 开关控制）   │
└──────────────────────────────────────────────┘
```

**技术栈**

| 类别 | 选型 | 版本 |
|---|---|---|
| 前端 | 原生 HTML / CSS / JavaScript（无构建步骤） | - |
| 图表 | Apache ECharts | 5.5.0 |
| 文件解析 | SheetJS (xlsx) | 0.18.5 |
| 报告导出 | html2canvas + jsPDF | 1.4.1 / 2.5.1 |
| 存储 | 浏览器 localStorage | - |

> 说明：当前版本的意图识别与 SQL 生成基于关键词/同义词规则引擎在前端实现，不依赖外部模型服务，离线可运行；代码中预留了流水线扩展点，可对接大模型 API。

## 四、安装与运行

### 在线体验（演示版）

<http://49.234.179.115:8001/databrain.html>

### 方式一：直接打开（最简单）

双击 `index.html`，用 Chrome / Edge 浏览器打开即可使用，无需安装任何环境。

### 方式二：本地静态服务器（推荐，避免个别浏览器的文件协议限制）

```bash
# 进入项目目录
cd DataBrain

# Python 3
python -m http.server 8080
# 或 Node.js
npx serve .
```

浏览器访问 <http://localhost:8080>。

### 环境变量 / 配置项

日志与埋点功能默认关闭，不影响任何核心功能。如需启用：

```bash
cp js/config.example.js js/config.js
```

编辑 `js/config.js`，填入飞书机器人 webhook 和埋点上报地址。**`config.js` 已被 .gitignore 忽略，请勿提交真实地址。**

## 五、快速上手

1. 打开应用，没有数据时点击「查看推荐问题」可进入**体验模式**（自动加载 3 张示例表，零门槛体验完整分析流程），也可直接进入「数据源」页上传自己的数据；
2. 上传一份 CSV/Excel（首行为表头），确认字段类型后导入；
3. 回到「新建查询」，用自然语言提问，例如：
   - 各区域销售额是多少
   - 按品类统计订单数量并画饼图
   - 最近 30 天销售趋势
4. 在流水线中确认系统生成的 SQL，执行后查看图表与分析结论；
5. 结果可保存到「智能报表」，支持导出。

## 七、常见问题

**Q：上传的数据会传到服务器吗？**
A：不会。文件仅在浏览器本地解析，数据保存在 localStorage，清除浏览器数据即完全删除。

**Q：断网能用吗？**
A：可以。第三方库已本地化到 `vendor/`，核心功能完全离线运行；仅日志/埋点需要网络，且默认关闭。
