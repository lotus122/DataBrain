# DataBrain — AI 数据分析平台

> 用自然语言对话完成数据查询、图表生成与分析报告的轻量级 BI 工具。上传 CSV/Excel 后，业务人员无需写 SQL，直接提问即可获得指标结果、可视化图表和智能分析报告。

## 一、项目介绍

DataBrain 面向“不会写 SQL 但有数据分析需求”的业务用户，提供对话式数据分析体验：

- **自然语言查询**：识别趋势、对比、占比、排行、明细等常见分析意图。
- **Agent 分析流水线**：意图识别、字段匹配、条件解析、SQL 思路生成、人工确认、图表渲染与追问推荐。
- **文件上传与解析**：支持 CSV、XLSX、XLS，内置 CSV 兜底解析。
- **自动可视化**：根据问题类型选择柱状图、折线图、饼图等，基于 ECharts 渲染。
- **智能报表**：查询结果可保存为报表，支持搜索、时间筛选、查看、复制与导出。
- **数据字典**：自动推断字段类型，维护中文别名、字段描述、指标和维度。
- **隐私安全**：业务数据仅在浏览器本地解析并存储于 localStorage，默认不向外部服务器上传。

## 二、技术架构

```text
浏览器单页应用（index.html）
├─ 交互层：对话查询、导航、数据源管理、报表预览
├─ 规则引擎：意图识别、字段匹配、SQL 思路生成与分析流程控制
├─ 数据层：SheetJS / 原生 CSV 解析、localStorage 本地持久化
├─ 可视化层：ECharts 图表、html2canvas 截图、jsPDF 导出
└─ 可观测层：可选埋点与飞书日志，默认关闭，配置文件不入库
```

| 类别 | 选型 | 版本 |
|---|---|---|
| 前端 | 原生 HTML / CSS / JavaScript，无构建步骤 | - |
| 图表 | Apache ECharts | 5.5.0 |
| 文件解析 | SheetJS (xlsx) | 0.18.5 |
| 截图导出 | html2canvas | 1.4.1 |
| PDF 导出 | jsPDF | 2.5.1 |
| 本地存储 | localStorage | - |

## 四、安装与运行

### 方式一：直接打开

双击 `index.html`，使用 Chrome / Edge / Firefox 等现代浏览器打开即可。核心功能不依赖后端服务。

### 方式二：本地静态服务器（推荐）

```bash
cd DataBrain
python -m http.server 8080
```

然后访问：

```text
http://127.0.0.1:8080
```

项目不需要 `npm install`，也没有构建步骤。`vendor/` 已包含第三方库，支持离线演示。

## 五、环境配置

默认公开版本不包含真实 Webhook 或埋点地址，外部上报全部关闭。

如需启用自己的日志服务：

```bash
cp js/config.example.js js/config.js
```

编辑 `js/config.js` 后，在 `index.html` 的本地 vendor 依赖之后加入：

```html
<script src="js/config.js"></script>
```

`.env.example` 用于后端部署或构建注入时对照；静态页面直接运行时不会读取 `.env`。禁止把真实 Webhook、服务器地址、密钥或 token 提交到公开仓库。

## 六、快速上手

1. 打开应用，在“新建查询”或“数据源管理”中上传 CSV / XLSX / XLS 文件。
2. 确认字段类型和表结构，在数据字典中查看指标与维度。
3. 输入自然语言问题，例如“按渠道分析销售额占比”。
4. 确认系统生成的分析方案和 SQL 思路，再生成图表。
5. 在“智能报表”中保存、筛选、复制或导出分析结果。

## 七、数据与隐私

- 上传文件默认只在当前浏览器中解析和保存。
- 默认不启用外部埋点、飞书机器人或后端上报。
- 内置埋点字段包含脱敏逻辑，接入外部服务前仍需确认接收端安全策略。
- 不建议上传包含身份证号、银行卡号、未脱敏手机号等敏感信息的真实生产数据。

## 九、常见问题

**Q：上传的数据会传到服务器吗？**
A：不会。文件仅在浏览器本地解析，数据保存在 localStorage；清除浏览器数据后即可删除本地记录。

**Q：断网能用吗？**
A：核心功能可以。第三方库已本地化到 `vendor/`；只有可选日志/埋点需要网络，且默认关闭。

**Q：为什么仓库里没有真实 config.js？**
A：`config.js` 可能包含 Webhook 或服务器地址，已被 `.gitignore` 忽略；公开仓库只提供 `config.example.js` 模板。
